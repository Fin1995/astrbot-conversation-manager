# Changelog

## 1.1.0 - 2026-10-18

- Simplified Chinese/English UI, Chinese by default; the language is persisted and `--lang en` is supported.
- Import tab shows conversation and message totals and lets you select the target conversation.
- Supports AstrBot's official JSONL export format (one conversation per line).
- Automatically detects AstrBot Desktop, Launcher, CLI, and source-checkout databases.
- Fixed some controls remaining in English after switching back from English to Chinese.
